A very simple python based airline ticket booking system that utilizes pandas, mysql and table display.
Includes both admin and user CLI. 
To run this project you will need mysql either from XAMPP or whatever software that runs it. 
Have fun exploring it. 
Will further update it if I have free time.

Steps to run:
1) Run XAMPP or other mysql software and make sure the address is correct
2) Install the necessary modules (IPython, sqlalchemy, pandas, and mysql.connector)
3) Run database_creator.py to create database for the system
4) Run the main file (Airplane Booking System.py)
5) Have fun!
